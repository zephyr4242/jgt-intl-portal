## ADDED Requirements

### Requirement: 显式双模式业务边界
门户 MUST 通过唯一配置显式选择 Mock 或 API provider；两种模式 MUST 返回相同领域字段、分页、状态和错误。API 模式失败 MUST NOT 回退 Mock。

#### Scenario: API 请求失败
- **WHEN** API 模式查询产品、交易、持仓、账单或帮助失败
- **THEN** 页面展示真实错误或未知状态，且不读取 Mock 成功数据

#### Scenario: Mock 可辨识
- **WHEN** 应用以 Mock 模式运行
- **THEN** 全局展示可辨识环境标识，且数据不包含真实客户身份或凭证

### Requirement: 人工审核后登录
门户 MUST 让注册申请进入人工审核；仅审核通过且凭证正确的操作员可建立会话。首页及全部业务页 MUST 受到登录保护。

#### Scenario: 注册提交
- **WHEN** 操作员提交合法且未重复的注册资料
- **THEN** 只显示待人工审核和联系入口，不返回 token 或自动登录

#### Scenario: 待审核或拒绝登录
- **WHEN** 待审核或审核拒绝的操作员尝试登录
- **THEN** 阻止进入业务页，并展示对应三语说明与联系入口

#### Scenario: 会话失效
- **WHEN** 操作员退出或会话失效后访问受保护页
- **THEN** 清理受保护状态并返回登录页

### Requirement: 产品列表到内部交易指令
门户 MUST 提供基金产品列表和“去交易”，只允许申购/赎回；提交前 MUST 校验金额或可用份额并展示风险确认。成功响应 MUST 表达内部指令已受理而非成交。

#### Scenario: 产品预选
- **WHEN** 操作员从产品行点击“去交易”
- **THEN** 交易页预选该基金并允许更换，不打开产品详情

#### Scenario: 幂等提交
- **WHEN** 操作员重复点击或同一业务意图发生网络重试
- **THEN** 同一 `Idempotency-Key` 只对应一条内部指令；结果未知时提示先查询记录且勿立即重提

#### Scenario: Excel 批量导入
- **WHEN** 操作员下载模板并导入不超过 100 行的 Excel 交易指令
- **THEN** 页面按交易账户、基金、方向、金额/份额、币种、最低申购额和累计可用赎回份额逐行校验，并在提交前展示明细预览

#### Scenario: 批量提交和部分未知
- **WHEN** 全部导入行有效且操作员确认提交批次
- **THEN** 每行使用独立稳定的 `Idempotency-Key` 提交并展示逐行受理/失败/结果未知；结果未知行提示先查询交易记录且不得立即重提

### Requirement: 账户记录与文件
门户 MUST 展示持仓、交易、分红、账单和只读账户信息；金额类字段 MUST 携带币种，不得无口径跨币种合计。只有可信有效 PDF 可预览、下载和打印。

#### Scenario: 多币种持仓
- **WHEN** 同一账户存在不同币种持仓
- **THEN** 按币种展示或汇总，不显示未经换算的单一总额

#### Scenario: 账单失效
- **WHEN** PDF 引用已过期、下载失败或不可预览
- **THEN** 停止打印/下载并提供重试或联系入口

### Requirement: 个人资料、三语和帮助
门户 MUST 分开显示机构账户与操作员资料；支持 zh-Hans、zh-Hant、en；帮助中心 MUST 提供分类、搜索、完整指南和持续可见联系方式，不提供在线工单。

#### Scenario: 三语一致
- **WHEN** 操作员切换任一支持语言
- **THEN** 正式导航、字段、状态、校验和操作数量保持一致

#### Scenario: 帮助无结果或失败
- **WHEN** 帮助搜索无结果或 API 查询失败
- **THEN** 显示清除/重试说明，并继续展示批准的国际业务联系方式

## MODIFIED Requirements

### Requirement: 真实登录注册接线
门户在 API 模式 MUST 调用 `/bus/jgt/intl/auth/*` 并保持 RSA 密码传输；注册成功后的行为修改为“产生待审核申请”，不得自动登录。Mock/API 模式由 `VUE_APP_DATA_SOURCE` 统一决定，`VUE_APP_DEMO_AUTH` 不再是长期业务开关。

#### Scenario: API 注册成功
- **WHEN** API 返回申请已提交
- **THEN** 页面显示申请编号与待审核状态，不建立会话
